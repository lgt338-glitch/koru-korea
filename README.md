# KORU Korea — B2B Wholesale Site

KORU ONE 자가급수 스마트 화분 한국 B2B 도매 사이트.

## 구성
- 정적 HTML/CSS/JS
- 다국어: 한국어 · English · 中文
- B2B 문의 폼 (mailto 전송)
- 800개 한정 재고

## 로컬 실행
브라우저로 `index.html` 직접 열기 또는:
```bash
npx serve .
```

## 배포
Vercel 자동 배포 (GitHub 연동).

## 관리자 도구
브라우저 콘솔에서:
- `viewInquiries()` — 접수된 문의 목록 보기
- `exportInquiries()` — CSV 다운로드
